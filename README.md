
Locust Location Tracker Application (L.L.T.A.)
=======================

> Save crops from locust attacks

## About

- LLTA tracks the realtime locusts location and visualizes wind patterns on earth.

- Predicts the probability of locust attacks on a particular given position through satellite imagery using machine learning models.

## Technologies

- Using Microsoft Azure services for creating APIs.
- Cesium Js framework to render and perform functions on 3D earth terrains and maps.
- Amazing Next Js features.
- ML model predictions from satellite imagery.

## Prerequisites

- [NextJS](https://nextjs.org)
- [Node.js 10+](http://nodejs.org)
